# Smart Bathtub IoT

Proyecto académico de **Internet de las Cosas (IoT)** que implementa una **Bañera Inteligente (Smart Bathtub)**, desarrollado como parte del curso *Internet de las Cosas* del Máster en Investigación en Ingeniería de Sistemas y de la Computación.

## Autora
**Brigitte Mariel Flores Mendez**

## Descripción
El sistema Smart Bathtub permite monitorizar y controlar distintos parámetros de una bañera mediante tecnologías IoT, mejorando la comodidad, seguridad y experiencia del usuario.

El sistema integra sensores, actuadores, comunicación en tiempo real y una interfaz gráfica de visualización.

## Tecnologías utilizadas
- Node-RED
- MQTT (Mosquitto)
- JavaScript
- Dashboard Web
- SQLite
- API REST(Métodos GET/POST)

## Funcionalidades principales
- Monitorización de temperatura del agua
- Control del volumen de agua
- Detección de presencia
- Control de iluminación
- Apertura y cierre de puerta
- Visualización de datos en tiempo real
- Registro histórico de consumo

## Arquitectura
El sistema se compone de:
- Capa de sensores y actuadores
- Capa de comunicación (MQTT y API REST)
- Capa de procesamiento (Node-RED)
- Capa de visualización y control (Dashboard Web)
